# DockNest 2.8.1

Large backups can now be downloaded as a normal ZIP.

## Fixed

- **Full ZIP download of large backups.** DockNest asked for far too much free space on the server (eight times the backup's size) and refused big sites. The ZIP now streams straight to your computer, so the server only needs about the backup's size plus 2 GB. The backup is still fully checked before anything is sent.
