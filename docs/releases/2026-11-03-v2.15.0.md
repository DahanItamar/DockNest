# DockNest 2.15.0

Make safe changes to sites, optionally restart unhealthy containers, and get alerts when they need attention.

## New

- **Safe Edit (beta).** Change a site's settings, ports or image from DockNest; it makes a backup first and puts the previous version back if the change does not come up.
- **Self-heal.** Optionally restart unhealthy containers for each site; it is off by default and pauses while other site work is running.
- **New alert events.** Choose alerts when a change is undone or needs you, and when Self-heal restarts a container or stops.

## Better

- Going back to an older version is blocked while a Safe Edit is unfinished, and updates wait for Safe Edit and Self-heal steps to finish.
