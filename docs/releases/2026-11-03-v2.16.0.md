# DockNest 2.16.0

Launch a new site straight from the Map, with HTTPS and backups from day one.

## New

- **Launch from the Map (beta).** Launch a new site from a Compose file or Git repository, with HTTPS and backups from day one.
- **Private Git repositories.** Use a read-only deploy key to launch from a private Git repository.
- **Launch needs you alert.** Get an alert when a failed launch could not remove everything it made on the server.

## Better

- Certificate renewals keep working while a maintenance page is on.
- Going back to an older version is blocked while a launch is unfinished.

## Fixed

- The Hardening findings window shows the full container name and fix on every screen size.
