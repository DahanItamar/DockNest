# DockNest 2.2.1

Released 2026-10-22. [Full changelog](../../CHANGELOG.md).

## Summary

A small fix release for the Update Center introduced in 2.2.0.

## What's new

Nothing new.

## Improved

- The release pipeline reads workflow runs directly instead of GitHub's filtered run search, which lags behind, and CI no longer runs on tag pushes.

## Fixed

- `install-updater.sh` creates the group for the api container's user when the host has none (the socket failed to start on hosts without a group for GID 1000).
- The Automatic checks switch in the Update Center is a slim pill switch again instead of a large square.

## Security

No security changes.

## Upgrade notes

From 2.2.0, use **Update to v2.2.1** in the Update Center, or `scripts/upgrade.sh --version v2.2.1`. Hosts that installed the updater with a manually created group need nothing; `sudo scripts/install-updater.sh --repair` picks it up.

## Known limits

Unchanged from [2.2.0](2026-10-22-v2.2.0.md).
