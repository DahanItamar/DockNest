# DockNest 2.14.0

See how safe each site is, free space on your servers, and hear about certificates before they expire.

## New

- **Hardening score.** Each Docker site gets a grade from A to F on its card and in the Map, with a one-line fix for each finding. DockNest only reads the settings and never changes the site.
- **Server cleanup.** On the Storage page, scan a server to see the space taken by stopped containers, unused images, unused anonymous volumes and old build cache, then remove them after you confirm. Anything a site, backup, restore test, move or kept old copy needs is never removed.
- **Certificate alerts.** Get an alert when a site's certificate expires within 14 days, or when renewal fails. Tick the two new events on an alert line in the Map, and change the number of days in Connections settings.

## Better

- Hardened sites, such as ones that drop all capabilities and add a few back, can now be restore tested.

## Fixed

- Restores, restore tests and moves now keep the original's security settings (read-only root, dropped capabilities, no-new-privileges, seccomp and AppArmor). A copy never runs with fewer protections; when a setting cannot be kept, DockNest stops and says why.
- Moving a Compose site that adds only Docker's default capabilities no longer stops at the Compose check.
