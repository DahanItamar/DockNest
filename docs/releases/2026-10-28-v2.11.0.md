# DockNest 2.11.0

Keep extra copies of your backups on other storage, choose storage per site, and S3 storage is out of beta.

## New

- **Backup copies.** Keep up to three extra copies of each site's backups on other destinations, for example an SFTP server plus an S3 bucket. Each copy keeps its own number of backups.
- **Storage per site.** A site can use its own main destination instead of the default one.

## Better

- If a site's main backup is missing or damaged, restore uses a verified copy. You can also pick the copy to restore from.
- A copy that fails retries on its own and sends an alert, and the site shows **Copy missing** until it works.
- S3-compatible storage is no longer beta.
- The storage report's savings card is now called **Possible saving**, because it estimates what incremental backups could save.

## Fixed

- Pressing Enter twice in **Connect storage** no longer sends the form twice.
- A ZIP download always contains plain files, even if a backup package claims a file is a link.

## Before you update

- Nothing changes until you add a copy or choose a site's own destination. If you go back to 2.10 later, copies already made stay where they are, and 2.10 restores from the main backup only.
