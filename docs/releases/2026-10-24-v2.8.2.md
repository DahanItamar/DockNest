# DockNest 2.8.2

Downloading a large ZIP now works behind Cloudflare and shows its progress.

## Fixed

- **Full ZIP download of large backups.** Clicking Download ZIP opens a window that checks the whole backup first and shows the progress and the time left. When it is ready, the download starts at once, so Cloudflare no longer cuts it off with error 524. You can close the window while it works. Nothing is stored on the server, and the download fails visibly if the backup changes while it is being sent.
