# DockNest 2.13.0

Docker sites back up with less setup, and DockNest can set up the maintenance page for you.

## New

- **Automatic maintenance page.** For sites behind nginx on the server, DockNest adds the page, tests it on your domain and undoes everything if a step fails. It is ticked when you add a site, and Check readiness offers it for existing sites.

## Better

- The maintenance page is optional. Without it a backup still runs, and the job warns that visitors may see an error for the few seconds the site is stopped.
- Jobs: the details icon comes first in the Details column, so it lines up on every row.

## Fixed

- A Docker site without a maintenance page could not be backed up, and the failed attempt locked the site even though nothing was stopped. Review recovery now unlocks a site once DockNest confirms it is healthy.
