# DockNest 2.7.0

A new Map you can work on like a flow: see servers, sites and backup storage connected, click anything for details, and move sites by moving their line.

## New

- **Map v2.** Servers, sites and backup storage as connected nodes. Click a node for its details; a site shows its domains, containers and the databases that move with it.
- **Move by reconnecting.** Pull a site's line off its server and drop it on another one. Save changes stays off until every site is connected again.
- **Install what a server is missing.** When a move needs nginx, Docker, Docker Compose or certbot, choose **Install** (you confirm with your password and code) or **Show command** to run it yourself.

## Better

- The map opens at regular size and fits the height of your screen; zoom out only when you want to.
- Messages when a server cannot take a site are short and say what to do.

## Fixed

- The Update now button was blocked for a day after a few attempts that changed nothing. Only real updates count now, and the message says when you can try again.
- On phones, "Move to…" shows long reasons in full and its buttons sit clear of the bottom of the screen.
- The new release notes are shorter and written for you, not for developers.

## Security

- Installing on a server uses only a fixed list of packages from the server's own sources, never removes anything, and needs a fresh password and code.

## Before you update

- After this update, run `sudo scripts/install-updater.sh --repair` once on the server, so the updater gets its fix.
