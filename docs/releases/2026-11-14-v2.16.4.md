# DockNest 2.16.4

Fix SQLite settings from the dashboard, clearer restore tests, and fewer refusals for common Docker setups.

## New

- **SQLite files in site settings.** Edit the database files of each service under Advanced backup settings. Services that declare the same files share one list.
- **Fix a failed backup in one click.** When a declared SQLite file is missing or became a link, the job shows the file and the service, with **Remove path** and **Open settings**.

## Better

- **Jobs.** A restore test is now one row, with its steps folded under it and the failed step highlighted.
- **Restore tests** now work for sites with fixed container IP addresses, and for sites where one container shares another's network (a sidecar).
- **Paths with commas.** Restores, restore tests, moves and Safe Edit no longer refuse a folder or mount path that contains a comma or a double quote.
- **Helper containers** such as postgres-exporter or redis-commander are no longer mistaken for databases when you back up a site.

## Fixed

- A backup that fails because a declared SQLite file is missing or became a link now names that file.
- Connections settings no longer shows a double line between its two switches.
