# DockNest 2.16.3

Safe Edit can now undo a Compose change, remove environment variables and checks changes more safely.

## New

- **Undo change.** Put a Compose file back as it was before your last Safe Edit change, with a backup first and an automatic rollback.
- **Remove an environment variable.** Review shows which services use it, and DockNest refuses to remove one the Compose file needs.
- **Time limit setting.** Choose how long Safe Edit waits for a site to come up (60 to 600 seconds) under Advanced on Review.

## Fixed

- Moving a site whose security settings name a seccomp profile now checks that the file is on the new server before the move starts, instead of failing at the end.

## Security

- Safe Edit checks a changed Compose file in an isolated view that shows only the site's own files, with no network and no Docker access. Sites whose Compose files read files from outside their own folders, and servers that run Docker from Snap or inside an unprivileged LXC container, may now show "Change it by hand".
