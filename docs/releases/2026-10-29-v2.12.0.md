# DockNest 2.12.0

Incremental backups arrive as a beta, and Connect storage now starts with your provider.

## New

- **Incremental backups (beta).** Off by default and set per site. A full backup is followed by 6 increments by default, holding only the files that changed in your mounts. Every restore point restores to a complete copy, from your main storage or a backup copy. Images are saved as before, so the saving comes from mount data, and the storage report shows what was saved. In our test, 7 restore points took 221.4 MB instead of 461.5 MB as 7 full backups (52% less).
- **Download chain.** An increment downloads as its encrypted packages plus an order file. ZIP is for full backups.

## Better

- Connect storage starts with a provider (own server or NAS, Hetzner, rsync.net, MinIO, Amazon S3, Cloudflare R2, Backblaze B2, Wasabi or another) and fills in its defaults, including the endpoint from your region or Cloudflare account ID. The buttons stay in view on small screens.
- The backup tree on the Storage page marks increments and points to the backup library for the chain download.

## Before you update

- Nothing changes until you turn incremental backups on for a site. Existing backups stay complete.
- After a backup that contains folder renames, the next backup is full.
- To go back to 2.11, turn incremental backups off for every site first, then make a backup. The order matters.
