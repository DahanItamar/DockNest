# DockNest 2.3.0

Released 2026-10-22. [Full changelog](../../CHANGELOG.md).

## Summary

A redesign of the whole interface: one consistent type scale, layouts that fit phones through 4K screens, plain status labels and clear red alerts. No change to backups, restores or stored data.

## What's new

None.

## Improved

- Every page uses one type scale and one set of components. Cards side by side have the same height and their actions on one line. Layouts use 1 to 4 card columns from phone to large screens, and the content stays centred on very wide screens.
- Statuses are a small icon and a word instead of coloured pills. Blocked or failed states show a red panel with the reason and the next step, and blocked buttons look disabled.
- Tables have fixed, aligned columns with one line per row, and row actions are plain icons.
- The Update Center shows only the new version and its release date, a plain "improvements and fixes" line instead of chips, and matching cards for automatic checks and the host updater.

## Fixed

- A failed job on the Overview was shown as a yellow notice; it is now a red alert with a link to the job.
- Dialogs no longer overflow on 390 px phones.

## Security

No security changes.

## Upgrade notes

From 2.2.2, use **Update now** in the Update Center, or `scripts/upgrade.sh --version v2.3.0`. No metadata migration; the interface changes only.

## Known limits

Unchanged from [2.2.0](2026-10-22-v2.2.0.md).

## Validation

Interface checks in the browser suites (mocked data, light and dark, 320 to 2560 px). Pending the private release validation on the release commit.
