# DockNest 2.6.0

Released 2026-10-23. [Full changelog](../../CHANGELOG.md).

## Summary

The Map: see all your servers and their sites in one picture, and move a site to another server by dragging it there. DockNest backs up the site, tests a copy on the new server and only then switches over. The old copy stays for 7 days so you can switch back.

## What's new

- **Map page.** Your servers and the sites on each one, arranged automatically, with zoom and Fit to screen. On phones it is a simple list.
- **Move a site to another server** (administrators). Drag the site onto the new server and press **Save changes**. **Ready to move** shows how long it takes, how long the site is offline and how long you can undo; **Advanced settings** holds the details. Press **Move**, follow the progress, and **Cancel** at any time before the switch. When DNS has to change, DockNest shows the one record to copy and waits for it, or changes it for you with an optional Cloudflare token. Afterwards: **Switch back** within 7 days, or **Remove old copy** when you are sure. See [moving sites](../moving-sites.md).

## Improved

- Faster checks for DockNest's own development: one CI run per change, and the long Linux suite only when a change is ready.

## Fixed

- Access: Status and Role are separate columns, aligned like the other tables, and Active shows its proper icon.
- Storage card buttons now really share the full width of the card.

## Upgrade notes

From 2.5.x, use **Update now** in the Update Center, or `scripts/upgrade.sh --version v2.6.0`. The database gets one additive migration (version 6) for the move journal; older releases ignore it. Finish or cancel any move before rolling back to 2.5.x.

A move never installs software on your servers, never overwrites existing folders and never deletes data unless you tick "also delete the old data" when removing the old copy.

## Known limits

- Real moves are validated by the two-host Linux Docker integration test only; the move feature is beta like the rest of DockNest.
- Outgoing email from the test copy is blocked only where Docker's firewall chain is available; the move preview says when it is not.
- Otherwise unchanged from [2.4.0](2026-10-23-v2.4.0.md).

## Validation

CI on every pull request, including the Linux integration suite (real backup, restore and a two-host site move). Pending the private release validation on the release commit.
