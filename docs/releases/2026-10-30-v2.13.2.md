# DockNest 2.13.2

Boot recovery installs on servers that already have backups.

## Fixed

- Boot recovery could not be installed on a server that had already made a backup or showed a maintenance page.

## Security

- DockNest's working folder on each server is now private to root. Other users can no longer list it; nginx can still reach the maintenance page inside it. Existing folders are fixed automatically.
