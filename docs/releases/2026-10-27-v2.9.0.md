# DockNest 2.9.0

DockNest can now check, on a schedule, that your backups really come back.

## New

- **Automatic restore tests (beta).** Pick a test server for a site. DockNest restores its latest verified backup there, starts it, checks it, shows the result and removes the copy. Daily, weekly or monthly. Off until you turn it on.
- **Storage report.** The Storage page shows space per site and per storage, growth over 30 days, and a rough estimate of what incremental backups could save.

## Before you update

- Nothing to do. Restore tests stay off until you choose a test server for a site.
- The test server receives a full copy of the site, including its passwords. Pick a server you trust as much as the live one.
- Before going back to 2.8.x, finish or cancel running tests.
