# DockNest 2.9.0

DockNest can now check, on a schedule, that your backups really come back.

## New

- **Automatic restore tests (beta).** Select **Restore tests** on a site and choose a test server. DockNest restores the latest verified backup there, starts it, checks it, shows the result and removes the copy. Daily, weekly or monthly. Off until you turn on **Auto tests**.
- **Storage report.** The Storage page shows space per site and per storage, growth over 30 days, and a rough estimate of what incremental backups could save.
- **New sign-in and setup pages.** A calm split screen with a show/hide password button and one short error message.

## Better

- **Mauve ink colours.** Softer neutrals with a hint of the DockNest purple, in light and dark, with better contrast in charts.
- **Safer sign-in message.** A wrong password or code now shows one message, so the page no longer tells anyone which part was wrong.
- **Maintenance pages** now end with a "Powered by DockNest" credit that links to the project.

## Fixed

- The Map details panel: copy buttons sit beside each value, long values are no longer cut off, and Alerts matches the rest of the panel.

## Before you update

- Restore tests stay off until you choose a test server for a site.
- The test server receives a full copy of the site, including its passwords. Pick a server you trust as much as the live one.
- Before going back to 2.8.x, finish or cancel running restore tests.
