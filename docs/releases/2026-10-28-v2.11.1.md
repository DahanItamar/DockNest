# DockNest 2.11.1

A clearer two-step sign-in, a working update button after command-line updates, and security hardening for backups and moves.

## Better

- Sign-in now asks for your password first, then the code from your authenticator app in six boxes. Paste or autofill fills them all, and you can type a recovery code instead.
- Number fields no longer show up and down arrows.

## Fixed

- After updating from the command line, **Update now** in the Update Center no longer stops with "cannot confirm which version is installed". If it ever needs a repair, it shows the command to run.

## Security

- Backups no longer copy password files, sudo rules or SSH keys that a container mounts from the server. The backup still runs, and the job shows which folders were left out.
- Moves only create folders in application locations, never in system folders, and never in a folder that already belongs to another program.
- Restores and moves refuse a backup that tries to use the server's own network, replace existing Docker images, or write files outside the site.
- The host updater checks more strictly that requests come from DockNest itself.

## Before you update

- If a site mounts a folder like `.ssh`, `/etc/ssh` or `/etc`, new backups leave it out. Keep a separate copy of those files, and move such a site by hand.
- If you update from the command line on a server where DockNest's folder is not owned by root, run `sudo scripts/install-updater.sh --repair` afterwards so **Update now** keeps working.
