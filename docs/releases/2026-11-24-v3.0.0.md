# DockNest 3.0.0

Know how long a restore takes, send clients a monthly proof page, keep backups on cloud drives, and protect NAS and Podman apps.

## New

- **Recovery time.** Each app shows how long it took to come back in its last passed restore test, on the dashboard, the Map and Restore tests.
- **Client reports.** Group apps per client and make a monthly PDF of backups, restore tests and recovery time, downloaded or emailed to up to 3 people.
- **Cloud drives.** Keep backups on Google Drive, OneDrive, Dropbox, WebDAV, an SMB share or a mounted local folder, with Reconnect when a sign-in expires.
- **NAS servers.** Connect Unraid, Synology and TrueNAS, with root or a non-root user that has passwordless sudo.
- **Podman and rootless Docker.** Apps on Podman or rootless Docker are found, backed up and restored. Restore tests run in the same engine on servers that can limit memory for that user. Not yet: apps managed by systemd units, native databases, several containers in one restore, incremental backups and moves.

## Better

- A new look across the dashboard, with one main button per screen.
- Keys safe, domain checks, backup coverage and linked apps help you see what a restore would miss.

## Before you update

- Backups of Podman and rootless apps cannot be restored by DockNest 2.16 or older.
- Cloud drives need an amd64 server. Moving an app between container engines is not supported yet.
