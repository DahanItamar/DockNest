# DockNest 2.8.0

Alerts in Telegram or email, set up on the Map like a flow, and a Map you can work on more freely.

## New

- **Alerts.** Add a Telegram or Email node on the Map, draw a line from DockNest, a server or a site, and choose what to hear about: backups failing or passing, moves finished or waiting for you, a server unreachable or low on disk, a new DockNest version. Open the node to set it up and press **Send test message**.
- **Credentials.** Save a Telegram bot or a mail account once and pick it in any alert node. Tokens and passwords are encrypted and never shown again.

## Better

- Click a node for more: a server's address, SSH user and port, host key, operating system and tool versions, with copy buttons; a site's ports, schedule and last backup size.
- Hover or select a node to light up everything it is connected to. All lines are solid.
- Move nodes around while you work, with **Undo**, **Redo** and **Tidy up**. The map sorts itself neatly again after you save.
- Drag a server, storage or alert from the **+** panel onto the map. The **+** beside a node only shows when nothing is connected yet.

## Before you update

- Nothing to do. Alerts stay off until you add a node.
