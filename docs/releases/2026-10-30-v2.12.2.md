# DockNest 2.12.2

Docker sites with temporary RAM folders now back up without extra setup.

## Better

- Edit configuration lists a site's temporary RAM folders for information only. There is no checkbox to tick.

## Fixed

- A site whose containers use temporary RAM folders (`tmpfs`), such as a read-only nginx container with `/var/run`, could not be saved or backed up. Every RAM folder is now recreated empty on restore with its original size and permissions. Only an unusual folder path or setting stops the backup, and the message names the container and folder.
