# DockNest 2.13.5

Restore tests work for more sites.

## Fixed

- Restore tests and restores now work for containers that add only standard permissions such as CHOWN, SETUID or SETGID. They used to stop with "Host privileges or shared namespace networking cannot be restored automatically".
- Boot recovery installs again when the server helper grows. If you installed boot recovery on a site, install it once more after updating.
