# Documentation screenshots

Generated by `npm run docs:screenshots` against an isolated local preview. All names, servers, addresses, recovery points, storage totals and chart activity are synthetic. No production APIs, accounts, backups or credentials are used. Screenshots use the current interface and a 2× display scale.

`job-details.png` was captured from an offline preview (no network access) seeded with a synthetic site (`shop.example.test`), a documentation-range server address and mock transfer numbers, at the same 2× scale.
