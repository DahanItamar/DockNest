# Documentation screenshots

Generated by `npm run docs:screenshots` (`scripts/readme-screenshots.js`) against a local Vite dev server (start one with `npx vite --host 127.0.0.1 --port 5199 --strictPort` and set `TEST_BASE_URL=http://127.0.0.1:5199`). Playwright intercepts every `/api` request and answers with fixtures defined in the script. All names, servers, addresses (`192.0.2.x`, `203.0.113.x`), domains (`example.com`), recovery points, storage totals and chart activity are synthetic. No production APIs, accounts, backups or credentials are used. Captures use a 2x display scale and are under 400 KB each.

| File | How it was produced |
| :-- | :-- |
| `dashboard.png` | Dashboard, 1440 px wide, light theme. |
| `dashboard-dark.png` | Same page with the `docknest-theme` local storage value set to `dark` and a dark color scheme. |
| `dashboard-mobile.png` | Same page at 402 x 874 (phone size). |
| `servers.png` | Servers page with three synthetic servers. |
| `backups.png` | Backup library with forty synthetic recovery points across eight sites. |
| `job-details.png` | Jobs page, details of a synthetic running backup with fixture transfer numbers and step diagnostics. |
| `map.png` | Map page, 1440 x 1300, light theme, after Fit to screen: the three synthetic servers and their sites. |
| `update-center.png` | Update Center with fixture update-check, release and host updater responses (an example update, not a statement about any release). |

`logo-blue.png`, `logo-purple.png` and `social-preview.png` are brand assets, not screenshots.

`map-move.gif` (the README hero) uses a separate fictional fleet in the same script (servers Frankfurt-1, Ashburn-1 and Home NAS, fictional sites). Render only it with `README_ONLY=hero npm run docs:screenshots`. It needs `ffmpeg` on the PATH. Set `SOCIAL_OUT=<file.png>` to also write a 1280x640 social preview image.

`map-move.gif` is a short story (dashboard, a backup job, a verified recovery point, a Map move). The same run writes `why-capture.png`, `why-verified.png` and `why-map.png` for the README feature blocks.
