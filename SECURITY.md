# Security policy

DockNest handles server access and encrypted backups, so security reports get priority.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report.

Include:

- what an attacker could do, and what access they need first
- steps to reproduce, using mock data only
- the DockNest version or commit you tested

Never include real credentials, server addresses, backups or customer data in a report.

## What to expect

- An acknowledgement within 7 days.
- An assessment and, for confirmed issues, a fix plan.
- Credit in the release notes once a fix is published, if you want it.

## Supported versions

Security fixes go to the latest release. See the [security model](docs/security.md) for how authentication, sessions and encryption work.
